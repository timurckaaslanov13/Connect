# Connect: состояние проекта

## Основание

Проверены локальный код, история Git и архив perepiska_chatgpt.zip. Архив содержит обсуждение обучения и инженерного качества, но не технический план последних изменений. Инструкции прежнего ассистента не считаются текущими поручениями пользователя.

Локальный HEAD при анализе: 278ea0b. origin указывает на https://github.com/timurckaaslanov13/Connect.git. Git ls-remote не смог проверить удалённый HEAD из-за ошибки Windows Schannel; веб-страница репозитория доступна. До начала работы уже существовали незакоммиченные WebSocket-файлы, изменения main.py и requirements.txt и тестовая HTML-страница.

## Реализовано в коде

- auth-service: регистрация, хеширование паролей, вход и JWT, текущий пользователь.
- user-service: создание, изменение и поиск профилей.
- chat-service: создание личного чата, список чатов, проверка членства.
- message-service: отправка и история сообщений с проверкой членства, начальная реализация WebSocket.
- Docker Compose: четыре сервиса и четыре PostgreSQL.

Redis, API Gateway, уведомления и полноценный интерфейс пока не реализованы. В репозитории есть конфигурация Alembic, но нет файлов ревизий миграций.

## Исправления после анализа

- Подключён WebSocket-router вместо повторного подключения HTTP-router.
- Тестовая HTML-страница использует ID чата и JWT в правильном URL; отправка проверяет состояние соединения.
- Исправлены отступы сборки списка чатов: работают пустой список и несколько чатов.
- WebSocket проверяет ограничение 5000 символов и удаляет соединение в finally.

## Проверка

Шесть автоматических проверок проходят. WebSocket проверяется через TestClient с SQLite и подменой проверки членства; проверены отсутствие/неверный токен, отказ неучастнику, валидация, сохранение, доставка двум клиентам и очистка соединений. Список чатов проверен с подменой зависимостей.

Из корня проекта, в окружении с зависимостями message-service, запускать отдельно (у сервисов одинаковое имя пакета app):

```powershell
python -m unittest discover -s services/message-service/tests -v
python -m unittest discover -s services/chat-service/tests -v
```

Docker Engine недоступен. Сквозной запуск четырёх сервисов с PostgreSQL не проверен.

## Следующие шаги

1. Добавить начальные миграции четырёх БД и проверить запуск на чистых томах без удаления существующих данных.
2. Проверить сценарий: два аккаунта → профили → личный чат → WebSocket → история сообщений.
3. Объединить HTTP- и WebSocket-отправку: сейчас HTTP сохраняет сообщение, но не рассылает его подключённым WebSocket-клиентам.
4. Устранить блокирующую работу синхронной БД в async-обработчиках; WebSocket сейчас удерживает сессию на всё время соединения.
5. Проработать доступ к внутреннему endpoint проверки членства, конфигурацию секретов (сейчас JWT-ключ и пароли заданы прямо в Compose), пагинацию истории и конкурентное создание чатов.
6. При переходе к нескольким процессам добавить доставку событий между ними: текущий ConnectionManager хранит соединения только в памяти одного процесса.
